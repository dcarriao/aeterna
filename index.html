Até 3 Pessoas

Indique seus contatos de confiança com ordem de prioridade.

Como funciona

1

Cadastro

Você cadastra suas senhas, vídeos e indica até 3 contatos com prioridades.

2

Prova de Vida

Periodicamente, o sistema verifica se você está ativo por e-mail.

3

Verificação

API consulta bases oficiais (CPF) para identificar falecimento.

4

Liberação

O sistema envia orientações para o primeiro contato da lista de prioridade.

📌 Prioridade: Você define a ordem. Se a primeira pessoa não responder, o sistema avança para a próxima.

🔒 Segurança e LGPD

🔐

Criptografia de ponta a ponta

Seus dados, sua chave. Nem nós acessamos suas senhas.

⚖️

LGPD - Você no controle

Seus dados não são compartilhados. Você pode solicitar exclusão a qualquer momento.

💡

Flexível e opcional

O cofre é opcional. Use apenas para indicar onde estão suas coisas, sem obrigação de guardar senhas.

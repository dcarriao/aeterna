Como funciona a liberação?

1

Cadastro

Você cadastra suas senhas, vídeos e indica até 3 pessoas de confiança com prioridades.

2

Prova de Vida

Periodicamente, o sistema verifica se você está ativo. Você recebe e-mails de confirmação.

3

Verificação Automática

Nossa API consulta bases oficiais (CPF) para identificar o falecimento de forma automática.

4

Liberação Inteligente

O sistema envia todas as orientações e acessos para o primeiro contato da lista de prioridade.

📌 Prioridade: Você define a ordem de quem receberá acesso. Se a primeira pessoa não responder, o sistema avança para a próxima automaticamente.

🔒 Segurança e Privacidade

🔐

Criptografia de Ponta a Ponta

Todas as suas senhas são criptografadas localmente antes mesmo de serem salvas.

  • Algoritmo Fernet (cryptography)
  • Chave derivada com PBKDF2
  • 32 bytes de criptografia simétrica
  • Seus dados só são descriptografados localmente
📋

LGPD - Seus dados, seu controle

Estamos comprometidos com a Lei Geral de Proteção de Dados (Lei 13.709/2018).

  • Seus dados não são compartilhados com terceiros
  • Você pode solicitar exclusão a qualquer momento
  • Dados armazenados apenas com seu consentimento
  • Transparência total sobre o que coletamos
🏦

Armazenamento Seguro

Seus dados ficam armazenados com os mais altos padrões de segurança.

  • SQLite com acesso restrito
  • Sempre criptografados em repouso
  • Apenas você tem a chave de acesso
🔒 Sua privacidade é nossa prioridade.
Suas senhas e mensagens pessoais nunca são acessadas por nós. Apenas você e as pessoas que você autorizar terão acesso.

🛡️ Como protegemos seu legado

🔐 Criptografia Aplicada

Utilizamos o algoritmo Fernet da biblioteca cryptography (Python), que garante:

  • Chave de 32 bytes
  • Criptografia simétrica AES-128 em modo CBC
  • Assinatura HMAC-SHA256 para autenticidade
  • Timestamp para evitar replay attacks

🗝️ Derivação de Chave

Sua senha mestra nunca é armazenada. Utilizamos PBKDF2 com:

  • 100.000 iterações
  • Salt único por usuário (32 bytes)
  • SHA256 como função hash

📁 Armazenamento Local

Todos os dados são criptografados antes de serem salvos:

  • Banco de dados SQLite criptografado
  • Dados em trânsito via HTTPS (TLS 1.3)
  • Seu navegador nunca envia senhas descriptografadas

⚖️ Conformidade com a LGPD

Direitos garantidos aos titulares:

  • Confirmação da existência de tratamento
  • Acesso aos dados pessoais
  • Correção de dados incompletos
  • Eliminação dos dados tratados com consentimento
  • Portabilidade dos dados
📌 Importante: A única pessoa que pode descriptografar seus dados é VOCÊ. Nem mesmo a equipe aEterna tem acesso às suas senhas ou mensagens pessoais. Guarde sua senha mestra com segurança - ela é insubstituível!
